# 松果项目部署手册

本手册适用于松果项目 2.x 版本，由运维小组维护。

## 环境

| 环境 | 地址 | 负责人 |
|---|---|---|
| 测试 | test.pinecone.example.com | 小林 |
| 正式 | pinecone.example.com | 阿青 |

## 发布流程

1. 合并到 main 后，CI 自动构建镜像。
2. 先部署到测试环境，跑完冒烟测试。
3. 测试通过后，由负责人在发布群确认，再部署到正式环境。

发布窗口是工作日 14:00 到 17:00，周五不发布。

## 回滚

正式环境出现问题时，按下面四步回滚：

```bash
# 先暂停新流量
./ops/traffic.sh pause

# 切回上一个镜像
./ops/deploy.sh --image previous

# 清空页面缓存
./ops/cache.sh flush

# 恢复流量
./ops/traffic.sh resume
```

回滚完成后，在发布群说明原因，并在当天补写故障记录。

## 数据库迁移

迁移脚本必须可以重复执行。上线前先在测试环境跑一遍，并保留回退脚本。
