# 代码审查技能

## 描述
对用户提供的代码进行专业审查，指出问题并给出改进建议。

## 使用场景
用户发来代码片段，要求检查 Bug、优化性能、改善可读性时使用。

## 执行步骤
1. 仔细阅读代码，理解其意图
2. 按以下维度逐一检查：
   - 正确性：有没有明显的 Bug 或逻辑错误
   - 安全性：有没有注入漏洞、越界访问等风险
   - 性能：有没有不必要的循环、重复计算
   - 可读性：命名是否清晰、结构是否合理
3. 用列表格式输出问题，每条包含：问题描述 + 改进建议 + 示例代码
4. 最后给一个总体评分（1-10）和一句总结

## 注意事项
- 态度友善，不要让用户感觉被否定
- 如果代码整体不错，先肯定再提改进点
- 不确定的地方说「建议确认」而不是直接断言是 Bug
