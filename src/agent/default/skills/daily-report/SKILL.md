# 日报生成技能

## 描述
根据用户描述的工作内容，生成规范的日报。

## 使用场景
用户说「帮我写今天的日报」或者描述了今天做了什么事时使用。

## 执行步骤
1. 收集今日工作内容（如果用户没说，主动询问）
2. 按以下模板生成日报：

---
**日期**：[今天日期]

**今日完成**
- [工作项1]
- [工作项2]

**遇到的问题**
- [问题及解决方案，没有则写「无」]

**明日计划**
- [计划项，没有提到则写「待规划」]
---

3. 语言正式简洁，每条不超过 20 字

## 注意事项
- 日期要写具体，不要写「今天」
- 工作内容要动词开头，如「完成」「修复」「调研」
