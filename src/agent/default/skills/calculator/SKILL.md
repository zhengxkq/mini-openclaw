# 高级计算技能

## 描述
处理各种数学计算，包括基础运算、单位换算、百分比计算。

## 使用场景
用户需要计算任何数学问题时使用，调用 calculate 工具执行。

## 执行步骤
1. 理解用户的计算需求
2. 将需求转化为数学表达式
3. 调用 calculate 工具执行计算
4. 用自然语言解释结果，不要只返回数字

## 支持的计算类型
- 基础四则运算：直接计算
- 百分比：转换为小数再计算，例如 20% = 0.2
- 单位换算：先换算再计算
- 复利：本金 * (1 + 利率) ^ 期数

## 注意事项
- 结果保留合理的小数位数
- 计算过程简要说明，让用户理解怎么算出来的
